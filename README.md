# Σύστημα Διαχείρισης Βιβλιοθήκης σε Java

### Περιγραφή

Το έργο υλοποιεί ένα σύστημα διαχείρισης βιβλιοθήκης μέσω κονσόλας σε Java, εφαρμόζοντας βασικές αρχές Αντικειμενοστραφούς Προγραμματισμού (OOP) και πρακτικές καθαρής αρχιτεκτονικής. Υποστηρίζει τη διαχείριση βιβλιοθηκικών αντικειμένων και μελών, τις διαδικασίες δανεισμού και επιστροφής, την αναζήτηση αντικειμένων, καθώς και τη δημιουργία αναφορών και στατιστικών.

Η εφαρμογή ακολουθεί δομημένη αρχιτεκτονική πακέτων, διαχωρίζοντας τα μοντέλα δεδομένων, τις διεπαφές, την επιχειρησιακή λογική και τα εργαλεία αναφορών, με στόχο την αρθρωτή σχεδίαση, τη συντηρησιμότητα και την επαναχρησιμοποίηση του κώδικα.

### Βασικές Λειτουργίες

- Διαχείριση βιβλίων, περιοδικών, ψηφιακού περιεχομένου και μελών.
- Αναζήτηση αντικειμένων και διαχείριση δανεισμών και επιστροφών.
- Δημιουργία αναφορών και προβολή στατιστικών.
- Εφαρμογή αρχών ενθυλάκωσης, κληρονομικότητας, πολυμορφισμού και αφαίρεσης.
- Χρήση Java Collections (`ArrayList`) και του `LocalDate API`.
- Έλεγχος εγκυρότητας δεδομένων και διασφάλιση της ακεραιότητάς τους.

### Τεχνολογίες

Java, Object-Oriented Programming (OOP), Clean Architecture, Interfaces, Java Collections, LocalDate API.

## README (English Version)

### Library Management System in Java

Description

This project implements a console-based Library Management System in Java, applying core Object-Oriented Programming (OOP) principles and clean architecture practices. It supports library item management, member registration, borrowing and returning operations, search functionality, report generation, and statistics.

The application follows a structured package architecture, using domain models, interfaces, a service layer, and reporting utilities to ensure modularity, maintainability, and code reusability.

Key Features

- Library item and member management
- Search, borrowing, and return operations
- Report generation and statistics
- Object-oriented design using encapsulation, inheritance, polymorphism, and abstraction
- Java Collections (`ArrayList`) and `LocalDate` API
- Input validation and data integrity checks

Technologies: Java, OOP, Clean Architecture, Interfaces, Java Collections, LocalDate API
